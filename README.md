# Linux Commands

A collection of **Linux commands and practice examples** covering fundamental and commonly used Linux command-line operations.

This repository is focused specifically on **Linux commands** used for file management, directory operations, system monitoring, process management, permissions, and other command-line tasks.

## 📚 Topics Covered

### Basic Linux Commands

- Displaying Current Directory (`pwd`)
- Listing Files and Directories (`ls`)
- Changing Directories (`cd`)
- Creating Directories (`mkdir`)
- Removing Directories (`rmdir`)
- Creating Empty Files (`touch`)
- Displaying File Contents (`cat`)
- Clearing Terminal Screen (`clear`)
- Displaying Command History (`history`)
- Displaying Text (`echo`)

### File and Directory Operations

- Copying Files and Directories (`cp`)
- Moving and Renaming Files (`mv`)
- Deleting Files and Directories (`rm`)
- Viewing File Contents (`cat`, `less`, `more`)
- Displaying First Lines of Files (`head`)
- Displaying Last Lines of Files (`tail`)
- Counting Lines, Words, and Characters (`wc`)
- Searching Files and Directories (`find`, `locate`)
- Searching Text in Files (`grep`)
- Comparing Files (`diff`)

### File Permissions and Ownership

- Changing File Permissions (`chmod`)
- Changing File Ownership (`chown`)
- Changing Group Ownership (`chgrp`)
- Viewing File Permissions (`ls -l`)
- Checking Default Permissions (`umask`)

### System Monitoring and Information

- Displaying System Information (`uname`)
- Checking Disk Space (`df`)
- Checking File and Directory Sizes (`du`)
- Checking Memory Usage (`free`)
- Monitoring System Processes (`top`, `htop`)
- Displaying Running Processes (`ps`)
- Checking System Uptime (`uptime`)
- Displaying Current User (`whoami`)
- Displaying Logged-in Users (`who`)
- Checking System Date and Time (`date`)

### Process Management

- Listing Running Processes (`ps`)
- Monitoring Processes (`top`)
- Terminating Processes (`kill`, `pkill`)
- Running Processes in Background (`&`)
- Managing Background Jobs (`jobs`, `bg`, `fg`)
- Running Commands with Persistent Execution (`nohup`)

### File Compression and Archiving

- Creating and Extracting Archives (`tar`)
- Compressing Files (`gzip`, `zip`)
- Decompressing Files (`gunzip`, `unzip`)

### Networking Commands

- Checking Network Connectivity (`ping`)
- Displaying Network Information (`ip`)
- Downloading Files (`wget`, `curl`)
- Checking Network Connections (`ss`, `netstat`)
- Connecting to Remote Servers (`ssh`)
- Copying Files Between Servers (`scp`)

### Linux Command-Line Utilities

- Sorting File Contents (`sort`)
- Removing Duplicate Lines (`uniq`)
- Extracting Columns (`cut`)
- Processing Text (`awk`, `sed`)
- Redirecting Command Output (`>`, `>>`)
- Using Pipes (`|`)
- Finding Command Locations (`which`)
- Displaying Command Manuals (`man`)

## 🎯 Purpose

This repository is created for:

- Learning and practicing Linux commands
- Understanding Linux file and directory operations
- Gaining hands-on experience with the Linux command-line interface
- Practicing file permissions, ownership, and process management
- Understanding system monitoring and troubleshooting commands
- Improving Linux command-line and shell skills
- Strengthening Linux knowledge required for Hadoop and Big Data environments
- Preparing for Linux, Hadoop, and Big Data-related interviews
